# 工作进度记录规则（强制）

## 规则

**每次任务完工后，必须更新项目根目录的 `PROGRESS.md`**，三段式记录：

1. ✅ **已完成（Done）** —— 已交付、可直接使用/验证的产物
2. 🚧 **进行中（In Progress）** —— 已开工未验收，需注明"做到哪一步"和"下一步"
3. ⬜ **未开始（Not Started）** —— 已知待办，按优先级排序

## 要求

- 三段都必须存在；无内容写 `（无）`，不得删除段落
- 每条含：**文件路径 + 一句话说明 + 验收方式**
- 新会话**先读 `PROGRESS.md` 再动手**；完工**立即回写**
- 文档与实际不符时，以代码为准并同步修正
